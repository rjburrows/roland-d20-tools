# Security policy

## Supported versions

Security fixes are applied to the current `0.2.x` release line.

## Reporting a vulnerability

Please do not publish a security-sensitive issue in the public tracker. Use
the repository's private vulnerability-reporting option, where enabled, or
contact the maintainers through the account listed on the repository page.

Include the affected command, a minimal non-sensitive reproduction, the
observed behaviour, and the expected safe behaviour. Do not attach private
MIDI/SysEx dumps or disk images.
